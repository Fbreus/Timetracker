# Time Tracker for VS Code v1.0.0

**Production-ready automatic time tracking extension with comprehensive analytics.**

## 🎯 Features

### Core Functionality
- ✅ Automatic activity detection (typing, file operations, debugging, terminal)
- ✅ Configurable idle detection and auto-pause (default: 5 minutes)
- ✅ Project-based tracking per workspace folder
- ✅ Start/stop/pause/resume tracking controls
- ✅ SQLite database for persistent local storage

### User Interface
- ✅ Sidebar panel with live timer and status indicators
- ✅ Real-time tracking status display
- ✅ Today's summary with per-project breakdown
- ✅ Full-featured analytics dashboard

### Data Management
- ✅ Manual time entry for work done outside VS Code
- ✅ Multiple export formats (CSV detailed, CSV summary, JSON, text reports)
- ✅ Date range filtering (today, week, month, all-time, custom)
- ✅ Activity logging for detailed session history

### Configuration
- ✅ 7+ configurable settings
- ✅ Idle timeout customization
- ✅ Project exclusion list
- ✅ Auto-start on workspace open
- ✅ Data retention policies

## 📦 Installation

### Method 1: From VSIX (Recommended)

1. Download `vscode-time-tracker-1.0.0.vsix` from this release
2. In VS Code, go to Extensions view (Ctrl+Shift+X)
3. Click the "..." menu and select "Install from VSIX..."
4. Select the downloaded file
5. Reload VS Code

### Method 2: From Source

```bash
git clone https://github.com/Fbreus/Timetracker.git
cd Timetracker
npm install
npm run compile
# Press F5 in VS Code to run
```

## 🚀 Quick Start

1. Open any workspace folder in VS Code
2. Click the Time Tracker icon (clock) in the Activity Bar
3. Tracking starts automatically!
4. View your stats in the sidebar and dashboard
